# Pick · 기획전 · 추천 전시 어드민 UX 재설계

**날짜**: 2026-05-10  
**대상 파일**: `src/app/admin/PickManagement.tsx`, `src/app/admin/CurationManagement.tsx`, `src/app/admin/FeaturedManagement.tsx`, `src/app/admin/ContentReview.tsx`(⭐ 추가)  
**승인**: 브레인스토밍 세션에서 사용자 확인 완료

---

## 배경

어드민 콘텐츠 큐레이션 3개 페이지를 목적 중심으로 재설계한다. 공통 문제:

| 페이지 | 현재 문제 |
|---|---|
| Pick 관리 | 편집기가 모달로 분리, 작품 검색이 편집기 안에 내장되어 좁고 복잡 |
| 기획전 관리 | 작품 클릭 → piece 펼침 2단계 선택이 불편, 화살표 버튼 순서 조정이 느림 |
| 추천 전시 | 전시가 쌓이면 미추천 목록이 수백 건으로 불어나 관리 불가 |

직전에 완료한 검수·신고·문의 재설계(분할 레이아웃 + 다크 헤더)와 동일한 패턴을 공유한다.

---

## 제품 정책 결정

**추천 전시 상한 없음.** 추천은 "피드 랭킹 부스트 태그" 개념이며 수량 제한을 두지 않는다. 관리 오버헤드를 낮추는 방향으로 설계한다.

---

## 1. Pick 관리 (PickManagement)

### 목표
픽 세션 생성·편집과 작품 선정을 한 화면에서 직관적으로 처리한다.

### 레이아웃

```
┌──────────────────┬─────────────────────────────────────────┐
│  픽 세션 목록     │  선택된 세션 — 전시 갤러리               │
│  (좌측 고정)      │                                         │
│                  │  [검색 바]                               │
│  ● 5월 2주차 ←   │  ┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐             │
│    활성·4개      │  │①  ││②  ││③  ││④  ││   ││   │         │
│                  │  └──┘└──┘└──┘└──┘└──┘└──┘             │
│  ○ 5월 3주차     │  ┌──┐┌──┐┌──┐┌──┐                       │
│    예정·0개      │  │   ││   ││   ││   │   ...             │
│                  │  └──┘└──┘└──┘└──┘                       │
│  ○ 5월 1주차     │                                         │
│    완료·8개      ├─────────────────────────────────────────┤
│                  │ [■][■][■][■]  4/10개  ⠿드래그  [임시저장] [발행] │
│  [+ 새로]        │ ← 하단 고정 바                           │
└──────────────────┴─────────────────────────────────────────┘
```

### 세션 목록 (좌측)

- 항상 표시 (드릴다운 없음)
- 각 행: 세션 제목 + 상태 뱃지(활성/예정/완료/임시저장) + 날짜 + 선정 수
- 활성 세션은 보라 왼쪽 테두리 강조
- 완료된 세션: `opacity-50`, 클릭 시 우측에 읽기 전용 갤러리
- `[+ 새로]` 버튼: 우측 패널에 세션 생성 폼 표시

### 세션 생성 폼 (우측, 신규 선택 시)

우측에 먼저 제목·기간 입력 폼이 뜬다. 저장하면 곧바로 갤러리 모드로 전환.

```
제목: [__________________]  (필수)
기간: [2026-05-11] ~ [2026-05-17]
배너 이미지 URL: [선택]
[저장 → 작품 선정으로]
```

### 전시 갤러리 (우측, 편집 시)

- 전체 공개 전시를 그리드로 표시 (최신순 기본)
- 상단 검색 바: 작품명·작가명 실시간 필터
- 클릭 = 선정 토글
- 선정된 전시: 보라 테두리(2px) + 우상단에 순서 번호 뱃지 (1~10)
- 선정 10개 초과 시 클릭 무시 + 토스트 "최대 10개까지 선정할 수 있어요"
- 완료된 세션(읽기 전용): 클릭 비활성, 선정된 것만 번호 표시

### 하단 고정 바

선정된 전시가 1개 이상이면 항상 표시.

```
[썸네일 ①][썸네일 ②][썸네일 ③]  N/10개 — 드래그로 순서 조정  [임시저장]  [발행]
```

- 썸네일: 선정 순서대로 나열, @dnd-kit 드래그로 순서 변경
- 드래그 중 순서 번호 뱃지 실시간 업데이트
- `[발행]` 클릭 → 기존 `publishPickSession()` 로직 실행 (이전 활성 세션 자동 종료)
- 활성 세션에 한해 `[게시 종료]` 버튼 추가 표시

### AC

- AC-01: 분할 레이아웃 — 세션 선택·변경 시 갤러리가 우측에서 업데이트
- AC-02: 전시 클릭 → 선정 토글 + 번호 뱃지 즉시 표시
- AC-03: 하단 바 드래그로 순서 변경 → 번호 뱃지 실시간 반영
- AC-04: 10개 초과 시도 → 토스트. 11번째 전시는 선정되지 않음
- AC-05: 새 세션 생성 → 폼 → 저장 → 갤러리 자동 진입
- AC-06: 발행 → 이전 활성 세션 자동 종료 (기존 로직 유지)

## 2. 기획전 관리 (CurationManagement)

### 목표
개별 이미지(piece) 선정을 빠르고 명확하게 한다. 현재 2단계 선택(작품 펼침 → piece 클릭)을 1단계로 단순화한다.

### 레이아웃

```
┌──────────────────┬─────────────────────────────────────────┐
│  기획전 목록      │  평면 이미지 갤러리                       │
│                  │                                         │
│  [배너] 봄의기억  │  [검색 바]                               │
│        piece 7개 │  ┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐             │
│                  │  │①  ││②  ││   ││③  ││   ││   │         │
│  [배너] 도시의빛  │  봄날  봄날  봄날  봄빛  봄빛  도시        │
│        piece 5개 │                                         │
│                  │  ┌──┐┌──┐┌──┐┌──┐                       │
│  [배너] 전통과현대│  │   ││   ││   ││   │                    │
│        임시저장  │  도시  전통  전통  노부부                  │
│                  │                                         │
│  [+ 새로]        ├─────────────────────────────────────────┤
│                  │ [■][■][■]  3개  ⠿드래그  [임시저장]  [게시] │
└──────────────────┴─────────────────────────────────────────┘
```

### 기획전 목록 (좌측)

- 배너 썸네일 + 제목 + piece 수 + 상태(게시 중/임시저장)
- 선택된 기획전: 파란 왼쪽 테두리 강조
- `[+ 새로]`: 우측에 기획전 생성 폼 (제목·부제·날짜 입력 → 저장 후 갤러리 진입)

### 평면 이미지 갤러리 (우측)

**핵심 변경**: 작품 단위 구분 없이 모든 전시의 모든 이미지를 한 그리드에 표시.

- 이미지 하단 라벨: 전시명 (짧게 truncate)
- 검색 바: 전시명·작가명으로 필터 (같은 전시 이미지들이 모여 표시됨)
- 클릭 = piece 선정 토글
- 선정된 piece: 보라 테두리 + 순서 번호 뱃지
- 비공개 전시의 이미지: `opacity-40` + "비공개" 오버레이 텍스트, 클릭 불가
- 이미 선정된 piece는 다른 기획전에서도 중복 선정 허용 (정책 §15.4 기존 동일)

### 하단 고정 바

Pick과 동일 패턴 (파란 배경으로 구분).

```
[썸네일 ①][썸네일 ②][썸네일 ③]  3개  ⠿드래그로 순서 조정  [임시저장]  [게시]
```

- @dnd-kit 드래그 순서 조정
- `[게시]` → 기존 `eventStore.update` 로직 + 작가 알림 (신규 piece 추가 시에만)

### AC

- AC-01: 기획전 선택 시 해당 기획전의 현재 선정된 piece들이 번호 뱃지로 표시된 갤러리 즉시 표시
- AC-02: 이미지 클릭 = piece 선정 토글 (번호 뱃지 즉시 반영)
- AC-03: 비공개 전시 이미지 클릭 불가 + "비공개" 표시
- AC-04: 하단 바 드래그로 piece 순서 변경
- AC-05: 게시 → 신규 추가된 piece의 작가에게만 알림 (기존 로직)

## 3. 추천 전시 (FeaturedManagement + ContentReview 연동)

### 제품 정책
추천 전시는 피드 랭킹 부스트 태그이며 상한 없음. 추천 전시가 시간이 지나면서 수백 건이 되어도 정상 상태.

### 진입 경로 2개

**경로 ①: ContentReview 검수 중 즉시 추천**  
검수 좌측 목록 각 행에 ⭐ 아이콘 추가. 대기중·승인 상태 모두에 표시.
- 빈 별(☆): 미추천. 클릭 → 즉시 추천, 별 채워짐
- 채워진 별(★): 추천 중. 클릭 → 즉시 해제
- 별도 저장 버튼 불필요. `workStore.updateWork(id, { featured: !prev })` ※ 구현 시 기존 `FeaturedManagement`의 실제 필드명 확인 후 사용

**경로 ②: 추천 전시 전용 페이지에서 추가/관리**

```
┌──────────────────────────────────────────┐
│  ⭐ 추천 전시  [추천 N개]  [+ 추천 추가]  │
├──────────────────────────────────────────┤
│  [썸네일] 봄날의 기록    구월    ★       │
│  [썸네일] 도시의 빛 2026 정호아트 ★     │
│  [썸네일] 전통의 선      은수워터컬러 ★  │
│  ...                                     │
│  (추천 중인 전시만 표시, ★ 클릭 시 해제)  │
└──────────────────────────────────────────┘
```

`[+ 추천 추가]` 버튼 → 갤러리 팝업:
- 전체 공개 전시, 최신 업로드 순
- 검색 바 (전시명·작가명)
- 클릭 → 즉시 추천 등록 + 목록에 추가
- 이미 추천 중인 전시는 ✓ 표시로 구분

### 기존 FeaturedManagement에서 변경 사항

- 체크박스 → ★/☆ 아이콘 토글로 교체
- 미추천 전시 목록 섹션 제거 (추천 중인 것만 표시)
- `[+ 추천 추가]` 버튼 + 갤러리 팝업 추가
- 검색: 현재 추천 중인 목록 내 검색으로 범위 축소

### AC

- AC-01: ContentReview 좌측 목록 각 행에 ★/☆ 아이콘 표시. 클릭 = 즉시 토글
- AC-02: 추천 전시 페이지 — 추천 중인 전시만 표시. ★ 클릭 = 즉시 해제
- AC-03: `[+ 추천 추가]` → 팝업. 검색 가능, 클릭 즉시 추가
- AC-04: 팝업에서 이미 추천 중인 전시는 ✓ 로 표시 (중복 추가 방지)

## 공통 패턴

| 요소 | 규칙 |
|---|---|
| 레이아웃 | 좌측 목록 + 우측 갤러리/편집기 분할 (검수·신고·문의와 동일) |
| 이미지 표시 | `imageUrls[key] \|\| key` 패턴 (PickManagement 버그 수정 완료) |
| 드래그 정렬 | `@dnd-kit` — BannerManagement·기존 PickManagement와 동일 |
| 하단 바 | 선정 항목 스트립 + 드래그 + 저장/게시 버튼 |
| 상태 변경 | 별도 저장 없이 즉시 반영 (추천 토글) 또는 명시적 저장 (픽·기획전) |

---

## 구현 순서 제안

1. **PickManagement** — 분할 레이아웃 + 갤러리 선정 (드래그 기존 패턴 재활용)
2. **CurationManagement** — 평면 갤러리 + 하단 바 (Pick과 동일 패턴)
3. **FeaturedManagement** — 추천 중 목록 + 팝업 추가
4. **ContentReview** — ★/☆ 아이콘 컬럼 추가 (소규모)
