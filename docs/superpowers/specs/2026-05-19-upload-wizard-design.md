# 작품 올리기 UX 개선 — 설계 문서

**작성일**: 2026-05-19  
**대상**: USR-UPL-01~03 (Upload 플로우 전면 개편)  
**범위**: `src/app/pages/Upload.tsx` UI/UX 재설계. 데이터 모델·스토어 로직 변경 없음.

---

## 배경

현재 Upload 화면은 캔버스+사이드바 구조로, 제목 입력·이미지 업로드·작가 지정·세부 정보 모달이 한 화면에 혼재한다. 시니어 사용자(타깃: 디지털 드로잉 중장년 작가)에게 다음 문제가 있다:

- 무엇을 먼저 해야 하는지 불명확
- 이미지별 작가 지정 탭 UI(회원/비회원)가 복잡하고 이미지마다 반복
- 마지막 "세부 정보" 팝업이 갑자기 등장
- 개인/그룹 모드 간 동일 기능이 다르게 동작하는 부분 존재

---

## 설계 방향

**4단계 linear wizard** — 한 화면에 하나의 할 일만. 단계가 명확하고, 완료된 단계는 클릭으로 돌아갈 수 있다.

모드 용어 확정:
- `uploadType: 'solo'` → **내 작품 올리기**
- `uploadType: 'group'` → **여러 작가 함께 올리기**

---

## 진입 경로

| 경로 | Step 0 | 특이사항 |
|---|---|---|
| 헤더 "작품 올리기" | 표시 | 기존 초안 있으면 토스트 → "이어서 작업할까요?" |
| `/upload?draft=id` | 건너뜀 | 초안 데이터 복원 후 Step 1. 발행 완료 시 초안 자동 삭제. |
| 마이페이지 수정 버튼 | 건너뜀 | 기존 작품 데이터 복원. Step 4 버튼 → "수정 저장" |
| 반려 알림·프로필 수정 | 건너뜀 | Step 1 상단 반려 사유 배너. Step 4 버튼 → "다시 검수 요청하기" |

---

## 공통 — 모든 단계

- **진행 표시바**: 완료(✓) 단계 클릭 시 해당 단계로 바로 이동
- **초안 저장**: 모든 단계에서 상시 접근 가능
- **화면 미리보기**: 이미지 1개 이상일 때 상시 접근 가능 (기존 `previewMode` 동작 유지)
- **이탈 방지**: 내용 입력 후 이탈 시 확인 다이얼로그 (기존 `useBlocker` 유지)
- **모바일 진행 표시바**: 현재 단계만 텍스트, 나머지는 아이콘만 표시

**기존 동작 그대로 유지 (설계 변경 없음)**  
파일 크기 초과(10MB) · 파일 형식 오류(JPG/PNG/WEBP/GIF) · 카메라 사진 차단(EXIF) · WebP 변환 진행바 · 비속어 필터(전시명·그룹명) · 10장 초과 방지

## Step 0 — 유형 선택 (변경 없음)

기존 큰 카드 2개 UI 유지. 선택 후 Step 1 진입.

---

## Step 1 — 작품 올리기

**화면 안내 문장**: "작품 파일을 올려주세요"  
**부제**: "디지털 드로잉 그림 파일 · 최대 10개 · JPG, PNG, WEBP"

### 기능
- 드롭존 / 파일 선택 버튼
- 업로드 후: 이미지 그리드 + 각 이미지 교체·삭제 툴바
- 재정렬 버튼 (이미지 2개 이상일 때만 표시)

### 다음 버튼 활성 조건
- 내 작품 올리기: 이미지 **1개 이상**
- 여러 작가 함께 올리기: 이미지 **2개 이상**

### 수정 모드 한정 안내 (Step 1 상단)
> "이미지를 바꾸면 다시 검수 대기로 돌아가요. 제목·그룹명만 고치는 건 즉시 반영돼요."

저장 후 토스트 분기:
- 이미지 변경 시: `upload.editModeToastPendingFromApproved`
- 메타(제목·그룹명)만 변경 시: `upload.editModeToastApprovedKept`
- 반려 재제출 시: `upload.editModeToast`

### 반려 재제출 진입 시
Step 1 상단에 반려 사유 배너 표시 (기존 `editingRejectedWork` 배너 위치 이동).

---

## Step 2 — 제목 짓기

**두 모드 동일 화면**  
**화면 안내 문장**: "전시 이름을 지어주세요"  
**부제**: "작품마다 이름도 따로 붙일 수 있어요"

### 필드

| 필드 | 조건 | 상한 | 비고 |
|---|---|---|---|
| 전시 이름 | 필수 | 20자 | 글자 수 카운터 표시 |
| 그룹 이름 | 여러 작가만 · 필수 | 20자 | 글자 수 카운터 · 이전 그룹명 자동완성 |
| 작품별 이름 | 선택 | 각 20자 | 이미지 썸네일 옆 나란히 · 카운터 |

### 안내
- 작품별 이름 입력칸 위: "이름을 입력하지 않으면 **'제목 없음'**으로 표시돼요"

### 다음 버튼 활성 조건
- 전시 이름 입력됨 + (여러 작가: 그룹 이름 입력됨)

---

## Step 3 — 작가 연결

**여러 작가 함께 올리기 전용. 내 작품 올리기는 이 단계 진행 표시바에서 숨김.**

### 3A — 작가 등록

**화면 안내 문장**: "이 전시에 참여한 작가를 알려주세요"  
**부제**: "이름은 여기서 한 번만 입력해요"

각 작가 등록 시 두 방식 선택:

**회원이에요** → 갤러리 닉네임으로 검색 (기존 회원 검색 로직 유지)  
- 본인 작품이 포함된 경우: 본인 닉네임을 직접 검색해서 추가

**아직 회원이 아니에요** → 이름 직접 입력 (필수)  
- 안내: "실명이든 별명이든 괜찮아요. 친구가 나중에 가입하면 자기 작품을 직접 찾아 연결해요."

`[+ 작가 추가하기]` 버튼으로 작가 추가.

**그룹 성립 조건 검증 (3A 완료 시점)**
- 게시자 본인 작품 포함 시: 타인 1명 이상 등록 필요
- 게시자 본인 작품 미포함 시: 타인 2명 이상 등록 필요
- 미충족 시: "함께 올리기는 서로 다른 작가 N명 이상이 필요해요" 안내 · 다음 불가

### 3B — 이미지 배분

**화면 안내 문장**: "각 작품이 누구 그림인지 골라주세요"  
**부제**: "탭 한 번으로 선택 — 작가마다 순서대로 진행해요"

작가 한 명씩 전담 화면으로 진행:
1. 현재 작가 카드 표시 (이름 + 회원/비회원)
2. "이 사람 그림을 골라주세요" 안내
3. 모든 이미지 그리드 — 탭으로 선택/해제 (이미지 전체가 탭 영역)
4. "N개 선택됨" 카운터
5. "완료 → 다음 작가" 버튼
6. 진행 인디케이터 "작가 2/3"

**미배분 이미지 처리**  
모든 작가 배분 완료 후 아직 배분되지 않은 이미지가 있으면:
- 해당 이미지 빨간 테두리 표시
- "아직 배분되지 않은 작품이 있어요" 안내
- 다른 작가에게 배분하거나 새 작가 추가 후 다음 가능

**수정 모드 — unknown 슬롯**  
이미 회원이 연결됐다가 해제된 슬롯:
- 3B 그리드에서 "작가 미상" 이미지로 표시
- 다른 작가에게 재배분하거나 "작가 미상 유지" 선택 가능
- 미상 유지도 배분 완료로 인정 (기존 `unknown` 타입 유지)

**수정 모드 — 3B 첫 진입 시 초기화**  
수정 모드에서 Step 3에 처음 진입하면 기존 `imageArtists` 배분 정보를 그대로 복원해 표시한다. 사용자는 변경이 없으면 그냥 통과할 수 있다.

**수정 모드 — Step 1 이미지 변경 후 3B 복귀**  
완료된 3단계에서 Step 1으로 돌아가 이미지를 추가·삭제하면:
- 추가된 이미지 → 3B 그리드에 미배분 상태로 추가
- 삭제된 이미지 → 3B 그리드에서 제거
- Step 1 이미지 변경 시 "작가 연결을 다시 확인해주세요" 안내

### 다음 버튼 활성 조건
모든 이미지 배분 완료 (미배분 0개)

---

## Step 4 — 전시 신청하기

**두 모드 동일 화면**  
**화면 안내 문장**: "거의 다 됐어요!"  
**부제**: "대표 이미지를 고르고 마지막으로 확인해주세요"

### 대표 이미지 선택

- **올린 작품 중 선택**: 이미지 그리드, 클릭으로 선택 (선택 시 파란 테두리 + "선택됨" 배지)
- **또는** 별도 커버 이미지 파일 올리기 (기존 `customCoverUrl` 유지)

### 동의 체크박스

**필수 — 모드별 분기**
- 내 작품 올리기: `upload.confirmOriginal` — "본인이 직접 창작한 원작임을 확인합니다"
- 여러 작가 함께 올리기: `upload.confirmStudent` — "참여 작가들의 동의를 얻었습니다"

**선택 (사전 체크)**  
`upload.consentCurationLabel` — "Proud's Pick·기획전에 선정될 경우 관련 페이지에 소개될 수 있음에 동의합니다."

### 검수 안내 (인라인, 팝오버 제거)

기존 `upload.reviewInfo*` 카피를 화면 하단 박스에 인라인으로 표시:
- 보통 1일 안에 검수가 끝나요. 결과는 알림으로 알려드려요.
- 이미지를 바꾸면 다시 검수 대기로 돌아가요.
- 반려되면 사유를 함께 알려드려요. 수정 후 다시 전시하면 새로 검수해 드려요.

### 신청 버튼 텍스트 분기

| 상태 | 버튼 텍스트 |
|---|---|
| 신규 | "전시 신청하기" |
| 수정 모드 | "수정 저장" (`upload.editModeSave`) |
| 저장 중 | "저장 중..." (`upload.editModeSaving`) |
| 반려 재제출 | "다시 검수 요청하기" (`review.editCtaResubmit`) |

필수 동의 미체크 시 버튼 비활성.

### 비회원 작가 확인 모달 (기존 유지)

신청 버튼 클릭 후, 비회원 작가가 있을 때만 자동 노출 (기존 `nonMemberPreviewModal` 로직 유지):
> "아래 작가들은 비회원으로 등록됐어요. 신청 직후부터 바로 초대 링크를 보낼 수 있어요."

비회원 없으면 바로 신청 완료.
