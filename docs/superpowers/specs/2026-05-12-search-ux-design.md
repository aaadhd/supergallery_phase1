# 검색 UI/UX 설계

**날짜**: 2026-05-12  
**프로젝트**: Proud Gallery (SuperGallery Phase 1)  
**상태**: 확정

---

## 1. 배경 및 목표

현재 검색은 결과를 4개 필드 섹션(작가/그룹/전시/작품명)으로 분리 표시하고 있어 구조가 복잡하고, "자동완성" 스타일의 상단 미리보기 카드가 노출되어 혼란을 준다. 타깃 사용자(시니어·중장년 작가)에게 직관적이고 단순한 검색 경험을 제공하는 것이 목표다.

**주요 사용 케이스:**
1. 이름을 아는 특정 작가 찾기
2. 주제·소재 키워드로 작품 탐색

---

## 2. 확정 설계

### 2.1 진입 방식

- GNB 검색 아이콘 탭 → `/search` 전용 페이지로 이동 (현행 유지)
- 메인 페이지 인라인 검색 도입 **안 함** — 브라우징 모드와 검색 모드의 명확한 분리가 시니어에게 중요

### 2.2 검색 방식

- **Enter 키**로 검색 실행 (실시간 자동완성 없음)
- 입력 중 화면 변화 없음 — 타이핑 도중 결과가 바뀌면 시니어 혼란 유발

### 2.3 빈 화면 (검색 전)

- 최근 검색어 칩만 표시
- 추천 작가, 인기 검색어 등 추가 요소 없음 — 심플하게 유지
- 최근 검색어는 개별 삭제(✕) + 전체 삭제 지원

### 2.4 검색 결과 화면

#### 결과 범위
아래 4개 필드 중 하나라도 키워드를 포함하면 결과에 포함:

| 필드 | 설명 |
|---|---|
| 작가명 | 전시 업로더(`work.artist.name`)의 닉네임 |
| 그룹명 | 그룹 전시의 그룹명(`work.groupName`) |
| 전시명 | 전시 제목(`work.exhibitionName`, `work.title`) |
| 작품명 | 개별 작품 제목(`work.imagePieceTitles[]`) |

- 동일 전시가 여러 필드에서 매칭돼도 **한 번만** 결과에 포함 (중복 제거)
- 정렬: **최신순** (`work.publishedAt` 내림차순)

#### 결과 단위

**둘러보기와 동일한 전시 카드.** 별도 카드 디자인 없음.  
작가 프로필 카드는 표시하지 않음.

#### 필터 탭

결과 상단에 필터 탭 항상 표시:

```
전체 N  |  작가명 N  |  그룹명 N  |  전시명 N  |  작품명 N
```

- **전체**: 4개 필드 중 하나라도 매칭, 중복 제거, 최신순
- **작가명**: `work.artist.name`에 키워드 포함된 전시만
- **그룹명**: `work.groupName`에 키워드 포함된 전시만
- **전시명**: `work.exhibitionName` 또는 `work.title`에 키워드 포함된 전시만
- **작품명**: `work.imagePieceTitles` 배열에 키워드 포함된 전시만

각 탭 숫자는 해당 필드 매칭 건수 (중복 미제거).  
결과 없는 탭도 표시하되 숫자 0으로 비활성 스타일.

#### 페이지네이션

없음. 전체 결과를 한 화면에서 스크롤로 확인.  
"더 보기" 버튼 없음. 다른 페이지 이동 없음.

#### 결과 없음 상태

- "'{키워드}'에 대한 결과가 없어요" 안내
- 최근 검색어 제안
