# Pick / 추천전시 어드민 필름스트립 UI 설계

**작성일**: 2026-05-17  
**상태**: 승인됨  
**대상 화면**: ADM-PCK (Pick 관리), ADM-FTR (추천전시 관리)

---

## 1. 문제 정의

현재 Pick·추천전시 어드민은 전시 썸네일 1장만 노출한다. 전시(`Work`) 단위는 1~10개의 이미지(작품)를 포함하는 컨테이너이므로, 썸네일 한 장으로는 어떤 작품이 포함되어 있는지 파악할 수 없다. 운영자가 전시 내용을 확인하려면 별도 화면으로 이동해야 한다.

---

## 2. 설계 목표

- 전시 단위로 포함된 모든 작품 이미지를 한 행에서 즉시 확인
- 클릭 최소화: 호버로 미리보기, 클릭으로 상세보기
- 세션 전환(주차별) 없이도 전시 목록 + 작품 전체를 한 화면에 파악

---

## 3. 레이아웃: 필름스트립

### 3.1 전시 행 구조

```
[ 전시 정보 컬럼 ] [ 작품 썸네일 행 (필름스트립) ]
```

**전시 정보 컬럼** (좌측 고정, 세로 정렬):
- 전시 제목
- 상태 배지: `초안` / `게시 예정` / `게시 중` / `종료`
- 기간 (YYYY.MM.DD ~ YYYY.MM.DD)

**필름스트립 영역** (우측, 가로 스크롤 없음):
- 작품 이미지를 54×54px 썸네일로 순서대로 나열
- 최대 11장 기준으로 한 행에 전부 표시 (가로 스크롤 없음)

### 3.2 인터랙션

| 동작 | 결과 |
|------|------|
| 썸네일 호버 | 240×240px 팝업이 커서 옆에 float — 작품 이미지 확대 표시 |
| 썸네일 클릭 | 모달 오픈 — 해당 작품 크게 표시 |
| 모달 내 ‹ › 버튼 | 같은 전시 내 이전/다음 작품으로 이동 |
| 모달 내 키보드 ← → | 이전/다음 작품 이동 |
| 모달 하단 dot indicator | 현재 위치 표시 |

### 3.3 세션 전환

Pick·추천전시는 복수의 세션(주차별)이 존재한다. 화면 상단에 세션 탭으로 전환 가능하며, 탭 전환 시 해당 세션의 전시 목록 + 필름스트립이 교체된다.

---

## 4. 발행 플로우

- 버튼: **"발행" 단일 버튼**
- 흐름: 제목·기간·작품 선택/수정 완료 → "발행" 클릭 → 확인 다이얼로그 → 확정
- 의미: 현재 상태를 날짜 기반으로 확정·적용하는 명시적 단계
  - 시작일 = Pick 배지 부여일
  - 기간 전체 = Pick 탭 게시 기간
- **상태와 무관하게 수정 후 발행 가능**: 게시 예정·게시 중 세션도 내용 수정 후 "발행" 재클릭 시 즉시 반영
- 종료 세션은 수정 불가 (이력 보존)
