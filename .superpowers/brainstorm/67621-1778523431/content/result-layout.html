2섹션(작가 + 전시·작품) 구조 — 어떤 방식이 좋아요?

A

작가 먼저, 전시는 큰 그리드

작가 카드 상단 강조 → 전시·작품 3열 그리드. 스크롤로 전체 확인.

B

섹션별 6개 + "모두 보기" 버튼

각 섹션은 6개만 미리보기. "모두 보기"로 전체 확인. 한 화면에 두 섹션 다 보임.
