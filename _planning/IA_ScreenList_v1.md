**본 문서의 목적**: Proud Gallery 서비스의 모든 화면·모달·오버레이를 단일 번호 체계로 정리한다. 상세 UI 동작·수용 기준은 사용자 PRD·어드민 PRD에서 다룬다.

## 0. 문서 읽는 법

### 0.1 대상 플랫폼

Proud Gallery Phase 1은 **웹 단일 플랫폼**이다. 네이티브 앱 래퍼 없음.

- **사용자 앱**: 웹(데스크톱) 우선 · 모바일 반응형. 루트 `/` 트리.
- **운영 어드민**: 데스크톱 우선(1280px 기준). `/admin` 하위.
- **인증·온보딩**: 독립 레이아웃(헤더·푸터 없음). `/login`·`/signup`·`/onboarding` 등.

### 0.2 다국어 전제

UI 기본 언어는 한국어(KO)이며 영어(EN) 전환 지원. 가입 폼은 한국·해외 분기 없이 모든 사용자에게 동일한 4가지 옵션(카카오·구글·애플 + 이메일 인증 링크)을 노출한다. 알림 채널은 사용자가 가진 연락처 기준으로 자동 라우팅된다 — 한국 전화번호 보유자는 카카오 알림톡(SMS 폴백), 그 외는 이메일. 상세는 [Policy §1](./Policy_v1.md#1-알림-채널-정책)·[Policy §2.1](./Policy_v1.md#2-1-가입-옵션과-필수-수집-정보-region-분기-폐기) 참조.

### 0.3 이 문서의 범위

- 화면 ID 체계 (§1)
- 사용자 앱 모든 화면·모달·오버레이 (§2) — 11 영역
- 운영 어드민 모든 화면·모달 (§3) — 13 영역
- 공통 팝업·다이얼로그 (§4)
- Phase 1 · Phase 2 우선순위 (§5)
- 열린 항목 (§6)
- 다음 문서 연결 (§7)

### 1.4 화면 카드 포맷

```
### [ID] · [화면 이름]
- 경로: [URL 또는 진입 동선]
- 구성: [화면 내 UI 블록을 영역 단위로]
- 연결: [이동 가능한 다음 화면 또는 모달 ID]
- 엔티티·정책: [엔티티(논리 모델) / Policy 섹션]
- 우선순위: [P0 / P1 / P2]
```

필요 시 `**노트**:` 로 특이사항 추가.

### 1.5 우선순위 플래그

| 플래그 | 의미 |
|---|---|
| **P0** | 런칭 필수. 이 화면 없이 서비스 불가. |
| **P1** | 런칭 권장. 1~3개월 내 도입. |
| **P2** | 로드맵. Phase 2 이후. |

## 2. Track 1 — 사용자 앱 (USR)

### 2.1 USR-AUT · 인증·온보딩 (USR-AUT-05·07 폐기)

#### USR-AUT-01 · 스플래시
- 경로: 앱 진입(세션·부트스트랩 체크 중) → 이 화면
- 구성: 로고 중앙 정렬 · 페이드 인·아웃 · 최초 진입 여부 플래그 · 로딩 인디케이터
- 연결: USR-BRW-01(기본), USR-AUT-02(로그인 필요 시)
- 엔티티·정책: 없음(로컬 상태만)
- 우선순위: **P0**

#### USR-AUT-02 · 로그인·가입 시트 (AuthSheet)
- 경로: `/login` (직접 진입 시 시트 자동 오픈) · 헤더 "로그인" 버튼 · 프로필 "로그인/회원가입하기" · 보호 액션(CM-02)
- 레이아웃:
  - **모바일**: 하단에서 올라오는 **바텀시트** (드래그 핸들 · 뒤 배경 딤)
  - **데스크톱**: 중앙 모달 다이얼로그 (동일 콘텐츠, max-w-md)
- 구성:
  - 상단 **브랜드 영역**: 태그라인("Live Artfully" 등) + 서비스 로고
  - **소셜 버튼 3종** (언어별 순서 — KO: 카카오·구글·애플 / EN: 구글·애플·카카오) — 카카오 노란 배경, 구글 외곽선·흰 배경, 애플 검정 배경. 버튼 문구는 **"[제공자]로 계속하기"**(가입·로그인 통합)
  - "또는" 구분선
  - **"이메일로 계속하기"** CTA (외곽선 버튼) → USR-AUT-03
  - 만 14세 이상 고지 문구(xs, muted)
- 시트 닫기: 드래그·바깥 탭·ESC — 닫으면 이전 화면 그대로. `/login` 직접 진입 시 닫으면 `/`로.
- 연결: USR-AUT-02b(이메일 로그인), USR-AUT-03(이메일 가입 CTA), USR-AUT-06(소셜 최초 가입 → 약관 동의), USR-AUT-10(온보딩 진입), USR-BRW-01(온보딩 완료 복귀), 보호 액션 진입 시 지정된 경로
- 엔티티·정책: USER_PROFILE, AUTH_SESSION · [Policy §2.1](./Policy_v1.md#2-1-가입-옵션과-필수-수집-정보-region-분기-폐기)
- 우선순위: **P0**

#### USR-AUT-02b · 이메일 로그인 (매직 링크 요청)
- 경로: 이메일 로그인 직접 진입 (`/login?mode=email`)
- 구성: 전용 페이지(모바일) 또는 시트 내부 전환(데스크톱) · **이메일 1개만 입력** + 형식 검증 · **"로그인 링크 보내기"** CTA · 뒤로가기(← 시트 상단으로). 비밀번호 필드 없음.
- 발송 후 상태(같은 화면에서 발송 완료 상태로 전환): 발송 안내 본문 + 스팸함 안내 + **"데모: 받은 로그인 링크 열기"**(QA 편의 · 실서비스 제거) + **"로그인 링크 다시 보내기"**(30초 쿨다운) + **"이메일 주소 수정"**
- 연결: USR-AUT-08(콜백), USR-BRW-01(성공 시 redirect)
- 엔티티·정책: USER_PROFILE, AUTH_SESSION, MAGIC_LINK_TOKEN · [Policy §2.5](./Policy_v1.md#2-5-이메일-인증-링크-매직-링크-가입-로그인)
- 우선순위: **P0**

#### USR-AUT-03 · 이메일 가입 Step 1 (이메일 입력 → 매직 링크)
- 경로: USR-AUT-02 시트의 "이메일로 계속하기" CTA → 가입 1단계 이메일 입력 화면
- 구성: **이메일 1개만 입력** + 형식 검증 · **"인증 메일 보내기"** CTA · 뒤로가기로 USR-AUT-02 복귀. 비밀번호 필드 없음. (진행 표시바 없음)
- 발송 후 상태: 발송 안내 본문 + 스팸함 안내 + **"데모: 받은 링크 열기"** + **"인증 메일 다시 보내기"**(30초 쿨다운) + **"이메일 주소 수정"**
- 연결: USR-AUT-08(콜백 → Step 2), USR-AUT-04
- 엔티티·정책: USER_PROFILE, MAGIC_LINK_TOKEN · [Policy §2.5](./Policy_v1.md#2-5-이메일-인증-링크-매직-링크-가입-로그인)
- 우선순위: **P0**

#### USR-AUT-04 · 이메일 가입 Step 2 (약관 동의)
- 경로: USR-AUT-08(매직 링크 검증) 성공 후 자동 이동 · `/signup?step=2`
- 구성: (진행 표시바 없음) · **"필수 약관 모두 동의" 마스터 토글** (indeterminate 지원, 필수 3종만 일괄 처리 — 마케팅은 별도 명시 동의 유지) · 필수 3종(이용약관·개인정보처리방침·"만 14세 이상이에요") 빨간 "필수" 태그 + 내용 확인 링크 · 선택 1종(마케팅 정보 수신 동의 — 단일 항목, 채널 자동 라우팅) 회색 "선택" 태그 · "이전" / "가입하기" CTA ([Policy §2.2](./Policy_v1.md#2-2-만-14세-검증)·[Policy §1.1](./Policy_v1.md#1-1-채널-라우팅))
- 연결: USR-AUT-10 (온보딩 진입), USR-INF-05, USR-INF-06, (이전) USR-AUT-03
- 엔티티·정책: USER_PROFILE · [Policy §2](./Policy_v1.md#2-가입-본인인증-정책) · [Policy §2.2](./Policy_v1.md#2-2-만-14세-검증) · [Policy §21.1 L-1](./Policy_v1.md#21-1-검토-필요-문서-3종)
- 우선순위: **P0**

#### USR-AUT-05 — 폐기 (USR-AUT-04에 통합)
- 가입 2단계와 3단계가 단일 화면(`/signup?step=2`)으로 구현됨. 약관 동의 전체 내용이 USR-AUT-04에 포함. 별도 Step 3 없음.

#### USR-AUT-06 · 소셜 최초 가입 모달
- 경로: USR-AUT-02 소셜 인증 성공 + 미가입자 판정 → 오버레이
- 구성: 안내 문구 · 약관 동의(필수 3 + 선택 1) · "모두 동의" 토글 · 제공자 이메일·닉네임 프리필(사용자 수정 가능) · "가입 완료" CTA
- 연결: USR-AUT-10
- 엔티티·정책: USER_PROFILE, SOCIAL_PROVIDER_FLAG · [Policy §2.3](./Policy_v1.md#2-3-중복-가입-차단)
- 우선순위: **P0**

#### USR-AUT-07 — 폐기 (매직 링크 도입)
- Policy §2.5 이메일 인증 링크 전환으로 비밀번호 개념 제거 → 비밀번호 재설정 경로 **폐기**.
- 잔존 이슈 없음(`/reset-password` 라우트·페이지 삭제 완료).

#### USR-AUT-08 · 이메일 매직 링크 콜백
- 경로: 이메일 매직 링크 클릭 후 진입
- 구성:
  - **검증 중** 상태 → 자동 진행
  - **성공(로그인)** → 세션 발급 후 보호 액션 진입 시 지정된 경로로 이동
  - **성공(가입)** → 입력한 이메일을 단말에 임시 보관한 채 가입 2단계(USR-AUT-04)로 이동
  - **토큰 파라미터 없음** → /signup 즉시 리다이렉트
  - **만료·무효·재사용** → "인증 링크가 만료됐어요" 화면 + "인증 메일 다시 보내기"(주 CTA) / "이메일 주소 수정"(보조 CTA) → 모두 /signup
- 연결: USR-AUT-02b(로그인 성공 후 redirect), USR-AUT-04(가입 이어가기), USR-AUT-02(재시도)
- 엔티티·정책: AUTH_SESSION, MAGIC_LINK_TOKEN · [Policy §2.5](./Policy_v1.md#2-5-이메일-인증-링크-매직-링크-가입-로그인)
- 우선순위: **P0**

#### USR-AUT-10 · 온보딩 Step 1 — 프로필 입력
- 경로: `/onboarding` (USR-AUT-04·USR-AUT-06 완료 후 직접 진입)
- 구성 (region 분기 폐기, 모든 사용자 공통):
  - 진행 표시 · **닉네임 필수 2~20자**(소셜 프리필 가능) · 프로필 이미지 선택(5MB, 원형 크롭) · AP +30 안내(UI 미노출)
  - 전화번호는 본 단계에서 묻지 않음(카카오 가입자는 OAuth 동의 시 자동 수집, 그 외는 Phase 1 수집 없음 — [Policy §2.1](./Policy_v1.md#2-1-가입-옵션과-필수-수집-정보-region-분기-폐기)). 실명은 Phase 1에서 어디에서도 수집하지 않음.
- 연결: USR-AUT-11(초대 토큰 없음) 또는 USR-AUT-10b(초대 토큰 보유)
- 엔티티·정책: USER_PROFILE · [Policy §2.1](./Policy_v1.md#2-1-가입-옵션과-필수-수집-정보-region-분기-폐기) · [Policy §2.2](./Policy_v1.md#2-2-만-14세-검증) · [Policy §7.2](./Policy_v1.md#7-2-적립-이벤트)
- 우선순위: **P0**

#### USR-AUT-10b · 온보딩 Step 2 — 본인 작품 찾기 (조건부)
- 경로: USR-AUT-10 완료 시 작가가 직접 보낸 초대 토큰(활성 또는 비활성)을 가진 가입자에게만 자동 진입. 토큰 없거나 만료·취소면 자동 스킵.
- 구성:
  - 헤더: "혹시 이 중에 본인 작품이 있나요?"
  - 안내문(주황 박스): "잘못 고르셨다면 작가님께 알려주세요. 작가님이 마이페이지에서 풀어주실 수 있어요."
  - 카드(2열 그리드, 비회원 슬롯 전부): 작품 이미지 + 작가가 적어둔 표시명 + 작품명 + "이거 제 작품이에요" 라벨
  - 카드 클릭 → 확인 다이얼로그 1회("'○○' 자리를 회원님 작품으로 연결할까요? · 잘못 클릭하셨다면 작가님께 알려주세요. 작가님이 마이페이지에서 풀어주실 수 있어요." / 네, 맞아요 · 취소)
  - "네" → 즉시 회원 슬롯 승격 + 작가에게 정보용 알림 1건 + 다음 step
  - "여기 없어요. 그냥 둘러볼게요" → 가입 완료, 카드 미선택 상태로 진행
  - 동시 선택 보호: 다른 가입자가 먼저 같은 슬롯을 가져갔다면 토스트 "이미 다른 분이 본인 작품으로 연결했어요." 표시 + 카드 자동 새로고침
