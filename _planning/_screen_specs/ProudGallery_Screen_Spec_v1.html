서비스 개요

v1.2

🎨 무엇을 하는 서비스인가

Proud Gallery는 시니어·중장년 순수미술 작가가 본인 작품을 디지털 갤러리에 전시하고, 가족·지인·동호회와 공유하는 플랫폼이다.

"여기는 게시판이 아니라 갤러리예요."

업로드 단위는 전시(Exhibition)다. 작품 한 점만 올려도 시스템이 자동으로 전시 페이지를 만들어준다.

👥 누구를 위한 서비스인가

  • 주 사용자 — 50~80대 순수미술 작가 (취미·동호회·복지관)
  • 보조 사용자 — 자녀·손주 (사용 보조 + 가족 관람)
  • 큐레이터 사용자 — 동호회 리더·그룹 전시 게시자
  • 관람 사용자 — 일반 디지털 미술 애호가

한국·해외 동등 지원. 한국어/영어 카피.

🌟 핵심 가치 (Phase 1)

  • 전시 단위 — 작품 1점도 전시 1개. 갤러리의 격
  • 자부심 모먼트 — "내 그림이 전시되었다" 감각
  • 그룹 전시 — 동호회·모임 함께 올리기
  • 친구 초대 — 본인 메신저로 직접 공유
  • 시니어 친화 — 큰 터치, 명확한 1차 CTA

비회원 초대 정책

v1.2
기본 모델

그룹 전시에 가입 안 한 작가가 포함된 경우, 그분이 본인 작품을 본인 프로필에 연결할 수 있도록 돕는 정책.

  • 작가는 비회원 슬롯에 이름만 입력
  • 검수 통과 후 전시 단위 공유 링크 활성화
  • 작가가 본인 메신저로 직접 공유
  • 받은 사람 가입 → "본인 작품 찾기" → 명시 클릭 → 즉시 자동 연결
  • 잘못 연결되면 작가가 마이페이지에서 슬롯 풀기
왜 이렇게 하는가
회사가 자동 발송하면 위험
한국 정보통신망법·EU GDPR·미국 CAN-SPAM·일본 특정전자우편법 모두 광고성 정보로 분류 위험. 카카오 알림톡 정책상 비회원 가입 권유는 채널 정지 위험.
친구 동의 없이 PII 수집은 위법
작가가 친구의 전화·이메일을 회사에 입력하는 것 자체가 친구의 동의 없는 제3자 개인정보 수집. 그래서 비회원 슬롯에는 이름만 받는다.
회원 본인이 직접 공유 = 합법 + 효과적
발신 주체가 회원 본인 → 사적 통신 → 광고 규제 적용 X. 받는 사람이 신뢰감 높음.
자동 연결 가드레일
  • "본인 작품 찾기" 화면에서 항상 명시 클릭 + 확인 다이얼로그 1번
  • "작가 미상" 슬롯은 매칭 후보에서 제외
  • 이미 다른 사람이 연결한 슬롯은 두 번째 사람 연결 불가 (안내 + 새로고침)
  • 잘못 연결은 작가가 풀기. 가입자 자가 풀기 진입점 X
초대 링크 상태
  • 활성 — 검수 승인된 전시. 정상 흐름
  • 비활성 — 검수 대기·반려. 친구 링크 보존, 재승인 시 자동 활성
  • 만료 — TTL 90일 경과
