## 3. 변호사 검토 핵심 포인트 (LP-1 ~ LP-11)

[Policy §21.2](./Policy_v1.md#21-2-검토-필요-정책-포인트)에 정리된 LP-1~10에 더해 LP-11(응모전 응모 시점 동의·게시 보존) 신설. 각 항목별로 **검토 대상**·**관련 정책**·**문서 내 위치**를 표시.

### LP-1. 만 14세 미만 차단의 근거·구현

- **정책**: [Policy §2.2](./Policy_v1.md#2-2-만-14세-검증) — 자가 입력 + 4단 정책 가드(시스템 차단, 약관 자기 명시, 거짓 입력 책임, 사후 신고 채널)
- **검토 포인트**:
  - 자가 명시 방식이 청소년보호법·정보통신망법 §31 적합성을 충족하는지
  - 카카오 가입자(인증 생년월일)와 그 외 가입자(자가 입력)의 분리 처리가 차별이 아닌 합리적 구분으로 인정되는지
  - 법정대리인 동의 기반 미성년자 가입 경로를 도입하지 않는 정책의 법적 리스크
- **문서 위치**: 약관 제4조·제7조·제12조 / 처리방침 §1.1·§2

### LP-2. 가입 시 수집 정보의 보관 기간·파기

- **정책**: [Policy §2.1](./Policy_v1.md#2-1-가입-옵션과-필수-수집-정보-region-분기-폐기)·[Policy §18](./Policy_v1.md#18-데이터-보관-저장-정책)
- **검토 포인트**:
  - 카카오·구글·애플 OAuth 인증 결과 + 이메일 매직 링크 토큰의 Phase 1 모의 단계 vs 백엔드 이관 후 저장 기간 (Policy v2.13에서 PASS 본인인증 전제 폐기됨)
  - 백엔드 이관 시 별도 보관 정책 수립 필요
- **문서 위치**: 처리방침 §1.2·§3


### LP-3. 비회원 초대 — 토큰 모델 적법 근거

- **정책**: [Policy §3](./Policy_v1.md#3-비회원-초대-정책) — 회사가 외부 채널로 초대 발송 안 함. 비회원 식별자(전화·이메일) 사전 수집 안 함. 작가는 **이름만** 입력. 검수 통과 후 작가가 본인 채널(카톡·문자 등)로 직접 토큰 링크 공유.
- **검토 포인트**:
  - 비회원 참여자 이름(작가가 입력)을 작품에 표시·저장하는 행위의 적법 근거 (이름만으로는 개인정보보호법상 개인정보에 해당하는지 케이스 검토 필요)
  - 가입자가 "본인 작품 찾기"에서 클레임하면 회원 슬롯으로 자동 승격되는 구조의 동의 근거
  - 토큰 링크 90일 TTL 후 자동 만료의 정합성
- **문서 위치**: 약관 제8조 / 처리방침 §1.5

### LP-4. 탈퇴 작가 작품 유지의 법적 근거

- **정책**: [Policy §4](./Policy_v1.md#4-탈퇴-작가-정책) — 탈퇴 시 작가명 "작가 미상" 익명화, 작품은 피드·검색에 유지
- **검토 포인트**:
  - 탈퇴자의 저작권 보유는 그대로지만, 작품 노출 유지가 탈퇴자의 개인정보 자기결정권을 침해하지 않는지
  - "작품 자체의 저작물성"·"열람자 권익"·"감상 표현 자유"라는 이익 형량 근거의 법적 강도
  - 탈퇴자가 자신의 모든 작품 삭제를 요청하는 경우의 처리 절차 (USR-INF-07 채널)
- **문서 위치**: 약관 제8조5·제12조2 / 처리방침 §3.1

### LP-5. 신고 처리 「삭제」 액션 사유 4종 한정의 법적 근거

- **정책**: [Policy §12.1](./Policy_v1.md#12-1-신고-처리-액션-어드민) v2.20·[Policy §22.7](./Policy_v1.md#22-7-운영자-감사-로그-원칙)
- **배경**: Phase 1엔 자동 비공개 트리거([Policy §12.2 v2.20](./Policy_v1.md#12-2-폐기-자동-비공개-정책))·시간 기반 자동 SLA 측정([Policy §22.2 v2.20](./Policy_v1.md#22-2-신고-처리-약속)) 모두 폐기. 모든 신고는 운영팀이 §12.1 3액션(삭제·기각·비공개 유지)으로 직접 판정.
- **검토 포인트**:
  - 「삭제」 액션 사유 4종(저작권 침해 / 위법 콘텐츠 / 청소년 유해 / 어뷰즈)이 정통망법 제44조의2(임시조치)·저작권법 제103조(복제·전송 중단)·청소년보호법 제16조 운영의무를 충족하는지
  - 운영자 감사 로그(§22.7) 5년 보관 + `targetSnapshot`에 작품 메타·사유·자유 메모·연결 신고 ID 동봉이 분쟁 시 증빙으로 충분한지(이미지 본문은 Phase 1 미보존 — 런칭 전 백엔드 연동 후 cold storage 보강 필요)
  - 「비공개 유지」 액션이 작가의 표현 자유를 부당히 제한하지 않는지 (작가 본인 프로필엔 노출 + [Policy §12.1.2](./Policy_v1.md#12-1-2-검수-상태별-수정-삭제-정책) 수정 후 재검수 진입 가능)
- **문서 위치**: 약관 제9조


### LP-6. 신고 처리 3액션의 사용자 고지 문구 통일

- **정책**: [Policy §12.1](./Policy_v1.md#12-1-신고-처리-액션-어드민)·[Policy §12.1.3](./Policy_v1.md#12-1-3-신고-처리-알림-전송-왕복-피드백)
- **검토 포인트**:
  - 삭제·기각·비공개 유지 3종 처리에 대한 신고자·작가 양측 알림 문구가 명예훼손 등 분쟁 발생 시 회사의 면책 근거로 충분한지
- **문서 위치**: 약관 제9조 / [Copy_v1.md](./Copy_v1.md) 신고·알림 관련 카피 참조


### LP-7. 데이터 내보내기·삭제 요청 (개인정보보호법·GDPR)

- **정책**: [Policy §30](./Policy_v1.md#30-개인정보-열람-정정-삭제-요청-정책)
- **검토 포인트**:
  - Phase 1은 USR-INF-07 수동 처리 + 운영팀 회신 방식. 셀프 서비스 UI(JSON 내보내기·자동 삭제) 도입 시점이 법적 요건을 만족하는지
  - GDPR Art.15(열람권)·Art.17(삭제권)·Art.20(데이터 이동권) 충족 여부
- **문서 위치**: 처리방침 §6

### LP-8. DPO(개인정보보호 책임자) 지정·공개

- **검토 포인트**:

- **문서 위치**: 처리방침 §10 / 푸터


### LP-9. 광고·마케팅 수신 동의 로그 보관

- **정책**: [Policy §1](./Policy_v1.md#1-알림-채널-정책)·[Policy §2.3](./Policy_v1.md#2-3-중복-가입-차단)
- **검토 포인트**:
  - 마케팅 수신 동의 단일 항목(채널 분리 안 함, 보유 식별자 자동 라우팅)의 명시 동의 적정성
  - 수신 거부 처리 이력의 보관 기간·증빙 가능성 (정보통신망법 §50)
  - 동의 철회 후 즉시 발송 차단의 기술적 보장
- **문서 위치**: 약관 제5조 / 처리방침 §2

### LP-10. 업로드 작품의 저작권 귀속·라이선스

- **정책**: [Policy §10](./Policy_v1.md#10-공유-정책)·[Policy §26](./Policy_v1.md#26-이미지-저작권-보호-정책)
- **검토 포인트**:

  - 탈퇴 후 사용권 유지 조항의 법적 강도
  - 작품 1200px 썸네일 제한·우클릭 차단 등 기술적 보호 조치가 약관에 명시될 필요가 있는지
- **문서 위치**: 약관 제8조·제10조


### LP-11. 응모전 응모 시점 동의·게시 보존

- **정책**: [Policy §15.5](./Policy_v1.md#15-5-응모전-선정-정책-런칭-전-필수)·[Policy §25.2](./Policy_v1.md#25-2-응모-조건)·[Policy §32.1](./Policy_v1.md#32-1-전시-삭제-시-정리-대상) #10
- **검토 포인트**:
  - **응모 시점 동의 모델의 약관규제법 정합성** — 사용자가 [USR-EVT-04](./PRD_User_v1.md#usr-evt-04-응모전-응모-모달) 응모 모달에서 응모전 응모 시 "선정 시 일정 기간 게시되며 게시 기간 중 본 전시를 삭제해도 운영팀 사본으로 게시 기간 종료일까지 유지" 항목에 명시 동의. 동의 안 하면 응모 차단. 약관규제법 §6 (소비자에게 부당히 불리한 조항)·§7 (예상하기 어려운 조항) 적용 시 무효 판정 리스크 검토.
  - **동의 잠금 vs 사후 철회 충돌** — GDPR Art.7(3) 동의 철회는 미래 처리에만 적용. 동의를 응모 시점 스냅샷으로 잠그고 발표 기간 중에는 철회해도 게시 유지하는 모델이 GDPR Art.7·개인정보보호법 §22 자유 동의 원칙에 부합하는지. 발표 기간(응모전별 운영팀 결정)이 합리적 한도라는 근거.
  - **공모전 표준 패턴과의 정합** — 사진·영상·디자인 공모전 응모 약관에서 일반적으로 통용되는 "수상작 N년간 주최측 사용권" 패턴과의 차이·유사성. 한국 표준약관(공모전 표준약관) 가이드라인 적용 시 본 모델이 권장 수준에 부합하는지.
  - **권리 침해 사유 즉시 제거 예외** — 신고 처리 "삭제"·저작권 침해 강제 삭제·명예훼손 등 권리 침해 사유는 동의 잠금 무관 즉시 제거. 이 예외 조항이 명시적으로 약관·동의 문구에 들어가 있는지.
  - **동의 이력 보존 기간·증빙** — Phase 1은 전시-응모전 연결(`connectedEventId`) 자체가 응모 시점 체크박스 통과의 증거로 갈음. 명시 CONSENT_LOG는 백엔드 도입 후 검토(작가 ID·전시 ID·응모전 ID·동의 시각). 정보통신망법 §50 마케팅 동의 이력 보관 의무에 준하는 기준 적용 검토.
- **문서 위치**: 약관 (어워드/공모전 응모 조항 신설 검토) · [Handoff_Event_Consent_v1.md](./Handoff_Event_Consent_v1.md) (응모 동의 문구 단일 소스 — Phase 1 본 LP 검토 후 신설)

## 5. 함께 검토할 정책 결정 (배경)

변호사가 약관·처리방침의 문구만이 아니라 그 배경의 운영 결정을 함께 이해하면 검토 정확도가 올라간다. 핵심 5개 결정:

### 5.1 Phase 1 백엔드 미연동·실서비스 출시 전 모집 단계

- 가입·인증·작품 저장 모두 클라이언트 + 모의 데이터 단계
- 카카오·구글·애플 소셜 로그인 실연동, 이메일 발송, 카카오 알림톡 모두 **런칭 전 백엔드 연동 후** 활성화
- 이 시기 약관·처리방침은 "백엔드 연동 후의 처리"를 미리 명문화하는 형태 → 변호사 검토 시점은 모집 시작 직전이 권장

### 5.2 지역 분기 없음 — 모든 사용자 동일 처리

- 한국·해외 분기 없이 모든 사용자에게 동일한 4가지 가입 옵션 ([Policy §2.1](./Policy_v1.md#2-1-가입-옵션과-필수-수집-정보-region-분기-폐기))
- 자동 country 수집 안 함 ([Policy §2.1.1](./Policy_v1.md#2-1-1-거주-국가-자동-수집-안-함))
- GDPR 적용 사용자(EU 거주자)는 분석 쿠키 기본 비활성으로 별도 처리

### 5.3 실명 미수집 (Phase 1)

- 가입·온보딩·설정 어느 단계에서도 실명을 받지 않음 ([Policy §2.1](./Policy_v1.md#2-1-가입-옵션과-필수-수집-정보-region-분기-폐기))
- 비회원 초대 매칭은 v2.14에서 폐기 — 작가가 토큰 링크를 본인 채널로 직접 공유하고 가입자가 본인 작품 카드를 명시 클릭 ([Policy §3](./Policy_v1.md#3-비회원-초대-정책))
- 표시는 닉네임으로 충분
- Phase 2에 정산·세무 등 실수요 발생 시 도입 검토

### 5.4 작가 단위 모더레이션은 Phase 1 범위 밖

- Phase 1은 **작품 단위** 신고·검수·운영팀 비공개 유지만 다룸 (자동 비공개 트리거는 [Policy §12.2 v2.20](./Policy_v1.md#12-2-폐기-자동-비공개-정책)에 따라 폐기, [Policy §12.3](./Policy_v1.md#12-3-phase-1-범위-밖-추후-이관))
- 사용자 계정 정지·시한부 차단·이의제기 절차는 Phase 1 범위 밖 → 약관 제12조에 계정 해지 조항만 둠
- 이 결정으로 약관·처리방침에서 "사용자 정지 절차" 관련 조항 일체 부재

### 5.5 마케팅 수신 동의 단일 항목

- 채널 분리(이메일·SMS·카카오 알림톡) 폐기, **단일 체크박스** ([Policy §1](./Policy_v1.md#1-알림-채널-정책)·[Policy §21.1 L-4](./Policy_v1.md#21-1-검토-필요-문서-4종))
- 발송 채널은 사용자 보유 식별자에 따라 자동 라우팅 (전화번호 보유 시 알림톡, 그 외 이메일)
- 기본 OFF, 명시 동의 후에만 발송

## 6. 변호사 검토 결과 반영 절차

1. 변호사 검토 의견 수령 → PM이 반영 사항 식별
2. **약관·처리방침** 본문 수정 → `Handoff_Terms_v1.md`·`Handoff_Privacy_v1.md`
3. 영향이 정책에 미치면 [Policy_v1.md](./Policy_v1.md) §21·관련 절 함께 갱신
4. 영향이 화면에 미치면 [PRD_User_v1.md](./PRD_User_v1.md) USR-INF-05·06·07 함께 갱신
5. 변호사 확정 표기를 본 체크리스트 §3·§4 표에 기록 (LP-N · T-N · P-N별 결과)
6. 사용자 모집 시작 전 [ADM-CKL-01](./IA_ScreenList_v1.md#adm-ckl-01-런칭-체크리스트) 런칭 체크리스트의 L-1·L-2 상태를 "확정"으로 전환
