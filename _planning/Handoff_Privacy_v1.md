# 개인정보처리방침 원고 v2 (변호사 검토용 초안)

`USR-INF-06` 및 가입·쿠키 동의 화면, 약관·푸터 링크에서 노출하는 개인정보처리방침 전달본.

> **이 문서의 성격**
> - 본 원고는 **PM이 정리한 변호사 검토용 초안**이다. 법적 효력을 가지는 확정본이 아니다.
> - 한국 개인정보보호법, 정보통신망법, GDPR(EU 사용자 대상) 등 적합성은 변호사 + 개인정보보호 책임자(DPO)가 별도 검토한다.
> - `[변호사 확인]` 표기 항목은 특히 검토가 필요한 부분이다.
> - 사용자 모집 시작 전 법무 확정본 게시 필수([Policy §21.0](./Policy_v1.md#21-0-법무-문서-단계별-마감-운영-가드)·[Policy §31 N-10](./Policy_v1.md#31-런칭-전-미해결-항목)).
> - 회사명·사업자등록번호·주소·DPO 이름·연락처는 변호사 검토와 함께 [Copy_v1.md §10](./Copy_v1.md#10-글로벌-푸터-원고) 사업자 정보와 정합 확인.

## 개인정보처리방침

`[회사명]`(이하 "회사")은 정보주체의 개인정보를 중요하게 생각하며, 개인정보보호법·정보통신망 이용촉진 및 정보보호 등에 관한 법률 등 관련 법령을 준수하기 위해 노력합니다. 본 처리방침은 회사가 운영하는 디지털 갤러리 서비스 "Artier"(이하 "서비스")의 개인정보 처리에 관한 사항을 알려드립니다.

- **시행일**: `[변호사 확인 후 확정]` (사용자 모집 시작일과 동일)
- **최종 개정일**: `[변호사 확인 후 확정]`

### 1. 수집하는 개인정보 항목 및 수집 방법

회사는 회원가입·서비스 이용·고객 응대를 위해 다음의 개인정보를 수집합니다.

#### 1.1 회원가입 시 필수 수집 항목 ([Policy §2.1](./Policy_v1.md#2-1-가입-옵션과-필수-수집-정보-region-분기-폐기))

| 항목 | 수집 방법 | 비고 |
|---|---|---|
| 이메일 주소 | 직접 입력 또는 소셜 계정에서 자동 수집 | 로그인 ID 및 알림 채널 |
| 닉네임 | 직접 입력 (소셜 가입 시 자동 채움 후 수정 가능) | 2~20자, 작가 표시명 |
| 생년월일 | 직접 입력 또는 카카오 가입 시 자동 수집 | 만 14세 검증 근거 |

#### 1.2 가입 옵션별 필수 동의 수집 항목

소셜 가입 시 해당 플랫폼 OAuth 필수 동의를 거쳐 다음 정보가 수집됩니다.

| 가입 옵션 | 필수 동의 수집 항목 |
|---|---|
| **카카오** | 이메일, 전화번호, 생년월일, 카카오 계정 식별자 ([Policy §31 N-14](./Policy_v1.md#31-런칭-전-미해결-항목) 필수 동의 설정 전제) |
| **구글** | 이메일, Google 계정 식별자 |
| **애플** | 이메일(릴레이 옵션 가능), Apple 계정 식별자 |
| **이메일 인증 링크** | 이메일 |

`[변호사 확인 — 카카오 소셜 로그인 동의 항목 노출 의무 명세 부합 여부]`

#### 1.3 가입 후 선택 수집 항목

회원이 설정에서 직접 입력하는 경우에 한해 수집합니다.

- **전화번호** — 알림톡·SMS 수신 목적([Policy §1.1](./Policy_v1.md#1-1-채널-라우팅)). 비회원 초대 연결은 전화 매칭이 아니라 토큰 링크·온보딩 「본인 작품 찾기」로 처리([Policy §3](./Policy_v1.md#3-비회원-초대-정책))
- 한 줄 소개(headline, 20자 이내)
- 바이오(200자 이내)
- 위치(11개 국가/지역 + 기타 중 사용자 선택. 자동 수집하지 않음. [Policy §2.1.1](./Policy_v1.md#2-1-1-거주-국가-자동-수집-안-함))
- 관심사(15개 칩 중 선택)
- 외부 링크(6개 플랫폼 한정)
- 프로필 사진(최대 5MB)

#### 1.4 서비스 이용 과정에서 자동 수집되는 정보

- IP 주소, 접속 로그, 쿠키, 브라우저 정보, 단말기 정보(OS·해상도 등)
- 서비스 이용 기록(작품 업로드·열람·인터랙션·검색어)
- Google Analytics 4 분석 정보(분석 쿠키 동의 시. [Policy §29](./Policy_v1.md#29-쿠키-분석-동의-정책))

#### 1.5 회원이 입력·업로드한 콘텐츠

- 작품 이미지(EXIF 정보는 카메라 사진 차단 판별 후 저장하지 않음. [Policy §11](./Policy_v1.md#11-카메라-사진-차단-정책))
- 작품명·전시명·그룹명·설명
- 작품에 함께 표시하는 비회원 참여자 이름(작가가 직접 입력)

`[변호사 확인 — 비회원 참여자 이름 입력의 적법 근거. Policy §3 토큰 모델로 식별자 사전 수집은 안 함]`

#### 1.6 Phase 1에서 수집하지 않는 항목

- **실명** — 가입·온보딩·설정 어느 단계에서도 입력받지 않습니다([Policy §2.1](./Policy_v1.md#2-1-가입-옵션과-필수-수집-정보-region-분기-폐기)).
- **주민등록번호·여권번호 등 고유식별정보** — 일체 수집하지 않습니다.
- **결제 정보** — Phase 1 무료 서비스로 일체 수집하지 않습니다.
- **거주 국가의 자동 식별 정보** — 사용자가 위치 항목에서 직접 선택한 값만 보관합니다.

### 2. 개인정보의 수집·이용 목적

회사는 다음 목적을 위해 개인정보를 수집·이용합니다. 수집된 정보는 다음 목적 외의 용도로 이용되지 않으며, 이용 목적이 변경되는 경우 별도의 동의를 받습니다.

| 목적 | 처리 항목 | 법적 근거 |
|---|---|---|
| 회원 식별·인증 | 이메일·소셜 식별자·생년월일 | 계약 이행 (개인정보보호법 §15①4) |
| 서비스 제공 | 작품·인터랙션·검색·알림 | 계약 이행 |
| 만 14세 검증 | 생년월일 | 청소년보호법, 정보통신망법 §31 |
| 본인 작품 클레임 (가입자 명시 선택) | 닉네임·이메일·이름(작가 입력) | 계약 이행, [Policy §3](./Policy_v1.md#3-비회원-초대-정책) (v2.14 토큰 모델 — 회사가 자동 매칭하지 않고 가입자가 본인 작품 카드를 명시 클릭) |
| 법적 의무 알림 발송 (약관·처리방침 변경 등) | 이메일 | 법적 의무 (개인정보보호법 §15①2) |
| 알림 발송 (검수 결과·신고 처리·응모전) | 이메일 또는 카카오 알림톡(전화번호 보유 시) | 동의 ([Policy §1](./Policy_v1.md#1-알림-채널-정책)) |
| 마케팅·응모전 정보 발송 | 이메일·전화번호(보유 시) | **선택 동의** (기본 OFF) |
| 부정 가입·이용 방지 | IP·쿠키·접속 로그·이메일·전화번호 | 정당한 이익 |
| 서비스 개선·통계 분석 | 이용 로그·GA4 익명화 데이터 | 동의 (분석 쿠키) |
| 운영팀 콘텐츠 검수·신고 처리 | 작품·신고 사유·작가 식별자 | 정당한 이익 (서비스 안전) |
| 분쟁 해결·법적 대응 | 가입 정보·접속 로그 | 법적 의무 |

`[변호사 확인 — 각 처리 목적의 법적 근거 분류(개인정보보호법 §15·정보통신망법 §22 적용 구분)]`

### 4. 개인정보의 제3자 제공

회사는 정보주체의 개인정보를 제1조에 명시한 범위를 벗어나 이용하거나 제3자에게 제공하지 않습니다. 다만, 다음의 경우에는 예외로 합니다.

1. 정보주체가 사전에 동의한 경우
2. 다른 법률에 특별한 규정이 있는 경우
3. 정보주체 또는 그 법정대리인이 의사표시를 할 수 없는 상태에 있거나 주소불명 등으로 사전 동의를 받을 수 없는 경우로서 명백히 정보주체 또는 제3자의 급박한 생명·신체·재산의 이익을 위하여 필요한 경우
4. 통계 작성 및 학술 연구 등의 목적을 위하여 필요한 경우로서 특정 개인을 알아볼 수 없는 형태로 제공하는 경우
5. 수사기관의 적법한 영장에 의한 요구가 있는 경우

`[변호사 확인 — 제3자 제공 항목 자체는 Phase 1에서 일반 정상 운영 중 발생하지 않으므로 본 항을 "현재 제3자 제공 없음"으로 단순화할지 검토]`

### 6. 정보주체의 권리·의무 및 행사 방법 ([Policy §30](./Policy_v1.md#30-개인정보-열람-정정-삭제-요청-정책))

정보주체는 회사에 대해 언제든지 다음 권리를 행사할 수 있습니다.

#### 6.1 행사 가능 권리

- **열람권** — 자신의 개인정보 처리 현황 확인
- **정정·삭제권** — 잘못된 정보의 수정 또는 삭제 요청
- **처리 정지권** — 특정 처리(예: 마케팅 발송) 일시 중지 요청
- **동의 철회권** — 수집·이용·제공·처리위탁에 대한 동의 철회

#### 6.2 행사 방법

- **Phase 1**: [USR-INF-07](./IA_ScreenList_v1.md#usr-inf-07-문의하기) 문의하기(경로 /contact) → "개인정보 열람·정정·삭제 요청" 카테고리 선택 후 신청
- **대체 채널**: 개인정보보호 책임자(DPO) 이메일로 직접 신청 (아래 §10 참조)

#### 6.3 처리 기한

| 요청 유형 | 기한 |
|---|---|
| 접수 확인 회신 | 영업일 5일 이내 |
| 처리 완료 | 접수일로부터 30일 이내 (1회 연장 가능, 연장 시 사유 고지) |
| 정당한 거부 사유 발생 시 | 10일 이내 거부 사유 안내 |

근거: 개인정보보호법 §35~37, GDPR Art.12(3) (EU 대상자)

#### 6.4 본인 확인

- 로그인 상태 요청은 세션으로 1차 확인합니다.
- 탈퇴자·비로그인 사용자는 가입 시 등록 이메일 주소에서 회신 형식으로 본인 확인을 진행합니다.
- 제3자 대행 요청은 위임장·신분증 사본 제출이 필요합니다.

### 7. 개인정보의 파기 절차 및 방법

#### 7.1 파기 절차

이용자가 입력한 정보는 보유·이용 목적이 달성되거나, 이용계약 해지·법령상 보존 기간 만료 시 즉시 파기됩니다. 다만 §3.2(법령 보존)·§3.3(운영 보존)에 해당하는 정보는 명시된 기간 동안 별도 안전 영역에 보관 후 파기합니다.

#### 7.2 파기 방법

- **전자적 파일 형태**의 정보: 복원 불가능한 방법으로 영구 삭제
- **종이 출력물**: 분쇄·소각

`[변호사 확인 — 파기 방법의 기술적 적정성 (개인정보의 안전성 확보조치 기준 §10)]`

### 8. 개인정보의 안전성 확보 조치

회사는 개인정보의 안전성 확보를 위해 다음의 조치를 취합니다.

1. **관리적 조치** — 내부관리계획 수립·시행, 임직원 정기 교육, 접근권한 차등화
2. **기술적 조치** — 비밀번호 인증 자체를 사용하지 않음(이메일 매직 링크·소셜 로그인), 비정상 접근 탐지·차단, 접속 기록 보관
3. **물리적 조치** — 외부 클라우드 서비스 데이터센터의 물리 보안 위탁

`[변호사 확인 — 개인정보의 안전성 확보조치 기준 고시 §4~§14 항목별 점검]`

### 9. 쿠키의 운용 및 분석 도구 ([Policy §29](./Policy_v1.md#29-쿠키-분석-동의-정책))

#### 9.1 사용하는 쿠키의 종류

| 카테고리 | 용도 | 동의 |
|---|---|---|
| **필수 쿠키** | 세션 토큰, 로그인 유지, 글꼴 크기 설정 | 동의 불필요 (서비스 제공 목적) |
| **분석 쿠키** | Google Analytics 4 응모전·페이지 조회 | **사용자 명시 동의 필요** |
| **마케팅 쿠키** | (Phase 1 미사용) | — |

#### 9.2 동의·거부 방법

- 최초 방문 시 화면 하단 배너에서 "모두 동의" / "필수만" 중 선택할 수 있습니다.
- 설정 메뉴에서 언제든 동의를 철회할 수 있으며, 철회 시 분석 스크립트가 즉시 비활성화됩니다.
- 분석 쿠키 거부 시에도 서비스의 핵심 기능 이용에는 제한이 없습니다.

#### 9.3 GDPR 대상 사용자

EU 거주 사용자에 대해서는 **분석 쿠키 기본 비활성** 정책을 적용하며, 명시 동의 후에만 활성화됩니다. `[변호사 확인 — GDPR Art.6 적법 처리 근거·Cookie Banner UX 적정성]`

### 10. 개인정보 보호책임자 (DPO)

회사는 개인정보 처리에 관한 업무를 총괄하여 책임지고, 개인정보 처리와 관련한 정보주체의 불만 처리 및 피해 구제 등을 위해 다음과 같이 개인정보 보호책임자를 지정합니다.

| 항목 | 내용 |
|---|---|
| **개인정보 보호책임자** | `[변호사 확인 후 지정 — 이름·직위]` |
| **연락처** | `[이메일 주소·전화번호]` |
| **개인정보 보호 담당부서** | `[부서명]` |

정보주체는 회사의 서비스 이용 중 발생한 모든 개인정보 보호 관련 문의·불만·피해구제 등에 관한 사항을 위 보호책임자에게 문의할 수 있으며, 회사는 정보주체의 문의에 대해 지체 없이 답변·처리합니다.

`[변호사 확인 — DPO 지정 의무 적용 여부(개인정보보호법 §31. Phase 1 사용자 규모에 따른 의무 발생 시점)]`
